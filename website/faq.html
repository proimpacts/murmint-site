Before you download

Is it free?

Yes. Murmint itself is free, with no subscription and no word limits. It uses an AI provider you choose (such as Groq, Cloudflare Workers AI or OpenAI) with your own API key, and you pay that provider directly for what you use, usually fractions of a cent per dictation. Groq and Cloudflare have free tiers, and a model on your own PC through Ollama or LM Studio costs nothing at all.

Do you steal my data?

No. An account is optional, and your dictation never goes through our servers. Your voice goes straight from your PC to the speech provider you picked, and your text to the formatting provider you picked. Audio is never stored. API keys are encrypted with Windows and only sent to their own provider. History is optional and stays on your PC. The whole app is open source, so anyone can check.

Why do I get a security warning when I install it?

Windows shows a "Windows protected your PC" (SmartScreen) warning for every app that isn't code-signed, and Murmint isn't code-signed yet because the certificate is expensive. It doesn't mean the file is dangerous. Click More info, then Run anyway. If you would rather not trust a download, you can read the source and build the installer yourself.

How do I install it?

Download the installer and run it. If Windows warns you, click More info, then Run anyway. Choose where to install and click Install; it takes a few seconds and needs no administrator rights. Then open Models, add an API key (or connect Ollama or LM Studio), click in any text box, hold Ctrl + Win, talk, and let go.

Will it be available for Linux or Mac?

Not yet. It's Windows only during the alpha. Linux and Mac are on the list for later.

Which AI provider should I use?

For the cheapest start, Groq or Cloudflare Workers AI. For the best formatting, add Claude or a GPT model for text alongside a speech model. Claude can't transcribe audio, so pair it with OpenAI, Groq or Cloudflare for the speech part. A ChatGPT subscription doesn't include API access.

Does it work in every app?

It types wherever your cursor is, using paste, and puts your clipboard back right after. If no text box is selected it looks for the app's message box, and otherwise offers Copy. Apps running as administrator and some games ignore pasted text.

Will it slow down my PC?

No. One small engine written in Rust does the work, and Murmint sits quietly in your tray until you hold the shortcut. See Performance for how much memory it uses.

How do I uninstall it?

Use Installed apps in Windows Settings, or the uninstaller in the Murmint folder. It asks whether to delete your settings, history and saved keys too.

How do I report a problem or contact you?

Email proimpacts@auralink.dev, or ask in the Discord if you're a tester.
