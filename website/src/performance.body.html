Why it's light

  • One Rust engine does the work. Dictation, text rules, the model router, your vocabulary, settings, history, keys, shortcuts and typing all run in one native program instead of a web page.
  • The interface is only the interface. The windows just show what the engine tells them, and the settings window can be closed while Murmint keeps running in the tray.
  • Nothing extra starts. Background features of the browser engine that Murmint never uses (translation, media casting, update checks, sync, accessibility trees, caches) are switched off, and there's no separate graphics process: drawing happens inside the main one.
  • Idle memory goes back to Windows. While Murmint sits in your tray, and after every dictation, it tells Windows to take back the memory it isn't using. It's only the unused pages, and they return in microseconds if they are needed, so nothing gets slower.
  • A closed window is gone. The window is built when you open it and removed completely when you close it, so a Murmint in the tray holds no window at all.

Why it feels quick

  • The microphone starts first. Finding which app you're typing into happens after recording has already begun.
  • The connections are warm. While you talk, the connections to your speech provider and to your formatting model are already open, so nothing waits for a handshake when you let go.
  • The text goes in first. Murmint pastes the moment the text is ready and puts your clipboard back in the background afterwards, so a dictation is finished about a third of a second sooner and the next one can start straight away.
  • Live models stream. With a live speech model, your words are transcribed while you speak instead of after.
  • One request to format. The whole dictation is cleaned up in a single request, sent to the best model you've set up, with a fallback if it fails.

Check it yourself

Hover over Murmint's tray icon and it shows its own total. Or open Task Manager, go to Details, and add up the memory of the Murmint processes. How fast text appears depends mostly on the speech and formatting providers you choose.

How these numbers were measured

Murmint's figure is from Windows 11, using the same measure as Task Manager's Memory column (private working set), added up over every Murmint process about 30 seconds after starting, with the app sitting in the tray as it normally does. Open the Murmint window and it rises to about 66 MB. The other dictation apps' figures are what reviewers and users report, not our own measurements, so they vary with the PC and the model you use, and some come from competing products' write-ups.
