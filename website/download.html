Murmint isn't code-signed yet. Windows may show a blue "Windows protected your PC" screen, or call the installer an unknown or unsafe file. That warning appears for every app that has not paid for a code-signing certificate. It doesn't mean the file is dangerous.

All of Murmint's source code is available, so you can read exactly what it does, or build the installer yourself with the steps below.

To run the installer anyway, click More info, then Run anyway.

Up and running in a minute

  1. Install

    Run the installer. It installs for your account only and needs no administrator rights. Murmint lives in the system tray.

  2. Sign in

    Sign in with Discord. Murmint downloads Murmint 1, its own free speech model, and you pick your shortcuts. For formatting, add an AI service on the Models page, such as Groq, Gemini or Cloudflare (all have free tiers), or Ollama on your PC.

  3. Talk

    Click in any text box, hold Ctrl + Win, and speak.

Prefer to build it?

You need Node.js 20 or newer, a Rust toolchain and the Visual Studio C++ Build Tools.

# get the source, then:
npm install
npm run engine   # builds the Rust core
npm start        # runs Murmint from the source
npm run dist     # builds the Windows installer

Good to know

Murmint types by pasting and restores your clipboard straight after. Windows running as administrator, and some games, ignore pasted text. It runs on Windows only for now.
